# MiniCPM-V Prompt Scripts for BMPT

This folder contains the prompt-side scripts used to generate MiniCPM-based pseudo labels and visual triples for BMPT. Because the MiniCPM-Llama3-V-2.5 checkpoint is large, the model weights are not included here. Please download and configure MiniCPM-Llama3-V-2.5 from the official Hugging Face page:

https://huggingface.co/openbmb/MiniCPM-Llama3-V-2_5

After downloading the model, update the local model paths in `extract_pseudolabel.py` and `extract_triples.py` before running the scripts.

## Files and Usage Order

### 1. `extra_frames.py`

Uniformly samples frames from each input video. By default, four frames are extracted from each video and saved as `1.jpg`, `2.jpg`, `3.jpg`, and `4.jpg` under a folder named after the video.

Before running, set:

```python
input_directory = "../Yourdir/somethingV2/20bn-something-something-v2/"
output_directory = "../Yourdir/ssv2_frames/"
```

Then run:

```bash
python extra_frames.py
```

The script currently processes `.webm` videos. If your dataset uses another format such as `.avi` or `.mp4`, modify the filename extension check in `process_videos`.

### 2. `extract_triples.py`

Uses MiniCPM-Llama3-V-2.5 to extract visual relationship triples from the sampled frames. The prompt asks the model to output only triples in the format:

```text
Entity: <subject> relation: <predicate> Entity: <object>
```

Before running, set the MiniCPM model path:

```python
chat_model = MiniCPMVChat("../MiniCPM-V-main/MiniCPM-Llama3-V-2_5/")
```

Also set:

```python
input_root = "../ssv2_frames/"
output_root = "../ssv2_des/"
```

Then run:

```bash
python extract_triples.py
```

Each output text file stores the raw MiniCPM responses for one video.

### 3. `triples_post_prosses.py`

Post-processes the raw triple descriptions generated by `extract_triples.py`. It parses MiniCPM outputs and saves normalized triples as plain text lines:

```text
subject relation object
```

Before running, set:

```python
input_dir = "../ssv2_des/"
output_dir = "../sssv2_des3/"
```

Then run:

```bash
python triples_post_prosses.py
```

The file name `triples_post_prosses.py` is kept unchanged for compatibility with the original release.

### 4. `extract_pseudolabel.py`

Uses MiniCPM-Llama3-V-2.5 to generate candidate pseudo labels for each original action label. Each input `.txt` file should contain one original action label.

Before running, set:

```python
MODEL_PATH = "../Yourmodel_dir/MiniCPM-V-main/MiniCPM-Llama3-V-2_5/"
INPUT_ROOT = "../input_texts/"
OUTPUT_ROOT = "../output_texts/"
NUM_CANDIDATES = 5
```

Then run:

```bash
python extract_pseudolabel.py
```

For each original label, the script saves MiniCPM-generated candidate pseudo labels to `OUTPUT_ROOT/<label>.txt`.

### 5. `select_final_label.py`

Selects the final pseudo label from the MiniCPM-generated candidates. It uses the CLIP text encoder to compute semantic similarity between the original label and each candidate, then penalizes lexical redundancy with a Jaccard-overlap score.

Before running, set:

```python
INPUT_ROOT = "../Yourdir/input_texts/"
OUTPUT_ROOT = "../Yourdir/output_texts/"
CLIP_MODEL_NAME = "ViT-B/32"
LAMBDA = 1.0
ALPHA = 0.3
DELTA_LOW = 0.60
DELTA_HIGH = 0.95
```

Then run:

```bash
python select_final_label.py
```

For each original label, the script saves:

- `OUTPUT_ROOT/<label>_final.txt`: the selected final pseudo label.
- `OUTPUT_ROOT/<label>_scores.txt`: the scoring report for all candidates.

## Complete Pipeline

Triple generation:

```bash
python extra_frames.py
python extract_triples.py
python triples_post_prosses.py
```

Pseudo-label generation:

```bash
python extract_pseudolabel.py
python select_final_label.py
```

The two branches can be run independently after the MiniCPM-Llama3-V-2.5 environment has been configured.
